# JSON Tools

Work with JSON without leaving the editor.

- **Format JSON** (`Mod+Alt+J`): two-space indentation
- **Minify JSON**
- **Sort JSON Keys**: alphabetically, at every level
- **Validate JSON**: reports the line and column of the first error

Works on the selection, or on the whole file when nothing is selected. The extension starts the first time you open a JSON file.

## Permissions

- **Read** and **edit** the active file.

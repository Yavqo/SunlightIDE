# Insert Tools

Insert generated text at every cursor.

- **Insert Date** (`Mod+Alt+D`): `2026-10-09`
- **Insert Time** and **Insert Date and Time**
- **Insert UUID**: a different random UUID at each cursor
- **Insert Placeholder Text**: a paragraph of lorem ipsum

The extension only starts when you first run one of its commands (lazy activation).

## Permissions

- **Read the active file** to find your cursors (so each one can get its own UUID).
- **Edit the active file** to insert the text.

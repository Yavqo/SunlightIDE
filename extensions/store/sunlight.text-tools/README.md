# Text Tools

Small, fast text transformations for the code you are editing.

Select some text first, or run a command with no selection to transform the **whole file**. With several cursors, every selection is transformed in one undo step.

## Commands

| Command | What it does |
|---|---|
| Sort Lines Ascending / Descending | Orders the selected lines (**Mod+Alt+S** sorts ascending) |
| Reverse Lines | Flips the order of the lines |
| Remove Duplicate Lines | Keeps the first occurrence of each line |
| Trim Trailing Whitespace | Removes spaces and tabs at the end of lines |
| Convert to camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, Title Case | Re-cases identifiers and phrases |
| Convert to UPPER / lower case | Changes letter case |

## Permissions

- **Read the active file** to find your selection.
- **Edit the active file** to apply the result.

Nothing leaves your computer: the extension has no network access.

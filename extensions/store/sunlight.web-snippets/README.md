# Web Snippets

Snippets for the web: HTML, JavaScript, TypeScript, CSS and Python.

Type a trigger such as `fetchjson`, `useState` or `grid3`, then press **Tab** to expand it.

| Language | Triggers |
|---|---|
| HTML | `ul`, `table`, `form`, `nav` |
| JavaScript | `fetchjson`, `useState`, `useEffect`, `component`, `debounce`, `promiseall` |
| TypeScript | `interface`, `fetchjson` |
| CSS | `center`, `grid3`, `dark`, `reset` |
| Python | `dataclass`, `argparse`, `trye` |

Snippets are plain data in `manifest.json`: this extension contains no code and needs no permissions.
